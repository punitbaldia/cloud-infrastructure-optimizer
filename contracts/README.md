# Shared integration contract

The source of truth is backend/app/schemas.py. OpenAPI and individual JSON schemas
are generated by backend/export_contracts.py. examples.json contains real API
responses captured from a disposable demo database.

- API base: /api/v1.
- Login: POST /auth/login, {username,password}; send Authorization: Bearer access_token.
- List envelope: {items,total,limit,offset,data_source}.
- Money: decimal strings with currency. Missing estimates: null.
- Dates: timezone-aware UTC; clients accept Z or explicit offsets.
- Resource id: internal UUID. resource_id: AWS/provider identifier.
- POST /scans returns 202 and job ID; poll GET /scans/{id}.
- Approval/dismissal: no request body required.
- GET /recommendations/{id}/preview describes mode, action and availability.
- Execution: POST /recommendations/{id}/execute with UUID idempotency_key.
- All demo executions return simulated=true. Live execution is server-gated.
- RDS findings are advisory.
- Settings and notifications are available through their corresponding endpoints.
- Errors: {error:{code,message,details}}.

## Cloud adapter

app/cloud/mock.py and app/cloud/aws.py expose:
validate_connection(connection)
collect_snapshots(connection,start,end)
collect_daily_costs(connection,start,end)

The backend supplies account/region/role configuration. Adapters return validated
ResourceSnapshot and DailyCost objects. Person 1's initial missing Python contracts
dependency has been replaced with the shared app.schemas models.

EC2 rule metrics:
cpu_percent: Percent, maximum, hourly sample count
network_bytes_per_hour: Bytes/hour, maximum, hourly sample count

RDS rule metrics:
cpu_percent, freeable_memory_bytes, database_connections, read_iops, write_iops.
Units and aggregations are checked by the detection rule.

Do not mix demo and live account data in one database.
